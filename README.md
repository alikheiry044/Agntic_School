
# Agntic_School
# Smart School Management System

A Python-based school management system built with FastAPI.

## Features

- Student and teacher management
- Authentication and access control
- Database models and schemas
- Administrative features
- AI-assisted services and analytics
- Telegram integration

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- Uvicorn

## Setup

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Configure the required environment variables in a local `.env` file.
5. Run the application using the appropriate entry point.

## Security

Do not commit credentials, API keys, environment files, or private database contents.
