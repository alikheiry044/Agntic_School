# Smart School Management System

A school management application built with Python and FastAPI.

## Features
- Student and teacher management
- Authentication and access control
- Admin, teacher, and parent interfaces
- AI agent and analytics modules
- Telegram integration

## Tech Stack
- Python
- FastAPI
- SQLAlchemy
- Pydantic
- Uvicorn

## Setup
1. Create a Python virtual environment.
2. Install dependencies using pip install -r requirements.txt.
3. Configure environment variables in a local .env file.
4. Run the application using its configured entry point.

## Security
Never commit API keys, passwords, .env files, or private database data.
